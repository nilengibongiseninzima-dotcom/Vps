Quick Start

  1. Select a server from the Servers tab
  2. Go to Config tab to view configuration
  3. Download or copy the config
  4. Import into your VPN app (OpenVPN, V2Ray, or SSH client)
  5. Connect and enjoy!

Supported Protocols

  • 🔒 OpenVPN UDP - Fast & Reliable
  • ⚡ V2Ray UDP - Ultra Fast
  • 🔐 SSH Tunnel - Secure

FAQ

Why is my connection slow?

Try switching protocols. V2Ray is usually fastest. Also, select a closer server location.

Can I use multiple servers?

Yes! Create as many as you need. FREE tier allows 1 month trial.

How do I report bugs?

Email: support@zivpn.com or use the GitHub issues page.
